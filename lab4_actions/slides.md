## 障眼法之一：动画状态机

角色任一时刻处于一个**状态**，每个状态一套四肢摆法：

```
            松开WASD             按住SHIFT
   ┌────────────────▶ Idle ◀───────────────┐
   │                   │  按WASD            │
   │                   ▼                    │
  落地               Walk ─────────────▶  Run
   │                   │                    │
   │                   │  按SPACE(在地面)   │
   └─────────────── Jump ◀─────────────────┘
```

判定优先级：**在空中 > 没动 > 冲刺 > 走路**（一串 if，已写好）
你的活儿：**每个状态"长什么样"**（Animator）

## 障眼法之二：一个 sin 走天下

没有美术做骨骼动画 → **用数学生成动作**：

```cpp
float swing = sin(phase);              // phase 随累计路程增长
legSwingL =  swing * 30°;   legSwingR = -swing * 30°;  // 双腿反相
armSwingL = -swing * 24°;   armSwingR =  swing * 24°;  // 手脚反相！
```

三个细节（写 Run 时照抄思路）：

1. **相位用路程驱动**（不是时间）：走快步频快，停下腿自动回正
2. **Run = Walk 的夸张版**：摆幅 30°→48°，手臂端起，重心起伏
3. **交叉对称**：左腿前摆时右臂前摆——现在起身走两步验证

## 障眼法之三：两行代码的物理引擎

高中物理 + **欧拉积分**，逐帧算：

```cpp
// 起跳（仅限落地时）
if (jump && onGround) vy = jumpSpeed;      // 4.5 m/s

// 之后每帧
vy += gravity * dt;      // 速度被重力削减   g = -9.8
y  += vy * dt;           // 位置被速度推动

// 落地
if (y <= 0) { y = 0; vy = 0; }
```

验证：跳跃高度 h = v²/2g = 4.5²/19.6 ≈ **1.03 米**
（策划要求"能跳上 0.8 米的箱子"→ 达标）

## 游戏手感的秘密（业界黑话时间）

同样的公式，参数不同，手感天差地别：

| 参数组 | 体验 |
|--------|------|
| g = -3 | 月球漫步，飘 |
| g = -9.8 | 写实，但玩家嫌"肉" |
| g = -30 | 灌铅，跳了个寂寞 |

## AABB：最便宜的碰撞检测

**轴对齐包围盒**：两个角点 min/max 描述一个盒子

相交判定 = 一维区间重叠的三维推广：

```
一维：[a1,a2] 与 [b1,b2] 重叠 ⟺ a1 ≤ b2 且 a2 ≥ b1

三维：X、Y、Z 三轴全部重叠才相交
      （任何一轴分离即不相交——分离轴定理的最简形式）
```

**6 个比较、1 条 return** = 商业游戏碰撞的第一道关卡（broad phase）

课堂快问：为什么叫"轴对齐"？旋转 45° 的房子怎么办？
（答：用外接 AABB 近似——看 world.h 里 addHouse 的注释）

## 碰撞响应：试探移动 + 分轴滑墙

检测到碰撞后怎么办？**试探移动**：先挪过去，撞了就退回来

```cpp
tryMove({dx, 0, 0});   // X 轴单独试：撞了作废
tryMove({0, 0, dz});   // Z 轴单独试：撞了作废
```

**分轴的妙处**——斜着撞墙时：

```
      墙 ████████████
    dir ↗   → 垂直分量被挡，平行分量放行
   小宇 ●───▶ 沿墙滑动，而不是被黏住
```

这个手感差异，试一次就懂（合轴处理 = 撞墙就卡死）
