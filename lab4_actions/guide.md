## 1. 知识加油站

### 1.1 动画状态机：角色的"心情"

角色任一时刻处于一个**状态**，每个状态对应一套四肢摆法：

```
            松开WASD             按住SHIFT
   ┌────────────────▶ Idle ◀───────────────┐
   │                   │  按WASD            │
   │                   ▼                    │
  落地               Walk ─────────────▶  Run
   │                   │                    │
   │                   │   按SPACE(在地面)  │
   └─────────────── Jump ◀─────────────────┘
```

判断优先级写成代码就是一串 if（在空中 > 没动 > 冲刺 > 走路）——
`Player::update` 里已经写好。**你的活儿是每个状态"长什么样"**（Animator）。

### 1.2 程序化动画：一个 sin 走天下

没有美术做骨骼动画（许可证还在采购流程里），我们用**数学生成动作**：

```cpp
float swing = sin(phase);                 // phase 随"累计路程"增长
legSwingL =  swing * 30°;  legSwingR = -swing * 30°;   // 双腿反相
armSwingL = -swing * 24°;  armSwingR =  swing * 24°;   // 手脚也反相！
```

细节控的三个彩蛋（写 Run 时照抄思路）：
- **相位用路程驱动**而不是时间：走快步频快，停下腿自动回正
- **跑步 = 走路的夸张版**：摆幅 30°→48°，臂端起（armLift→12°），加"重心起伏"
- **交叉对称**：左腿前摆时右臂前摆——不信你现在起身走两步验证一下

### 1.3 跳跃：两行代码的物理引擎

高中物理的匀加速直线运动，用**欧拉积分**逐帧算：

```cpp
起跳（仅限落地时）：  vy = jumpSpeed;          // 给一个向上的初速度
之后每帧：           vy += gravity * dt;       // 速度被重力削减
                    y  += vy * dt;            // 位置被速度推动
落地（y ≤ 0）：      y = 0; vy = 0;
```

跳跃高度的验证公式：h = v²/2g = 4.5²/19.6 ≈ **1.03 米**（策划要求"能跳上箱子"，达标）。

**游戏手感的秘密**：很多平台跳跃游戏（如《空洞骑士》）会在下落时偷偷放大
重力，让跳跃"干脆利落"。写完基础版后试试 `vy < 0 ? gravity * 1.8 : gravity`。

### 1.4 AABB：最便宜的碰撞检测

给每个道具套一个**轴对齐包围盒**（Axis-Aligned Bounding Box）——
两个角点 min/max 就能描述。相交判定是**一维区间重叠**的三维推广：

```
一维：[a1,a2] 与 [b1,b2] 重叠 ⟺ a1 ≤ b2 且 a2 ≥ b1
三维：X、Y、Z 三个轴全部重叠才相交（任何一轴分离即不相交——分离轴定理）
```

6 个比较、一条 return，就是商业游戏碰撞检测的第一道关卡（broad phase）。

### 1.5 碰撞响应：试探移动 + 分轴滑墙

检测到碰撞后怎么办？本项目用最经典的**试探移动**：

```cpp
tryMove({dx, 0, 0});   // X 轴单独试：撞了就作废这个轴的移动
tryMove({0, 0, dz});   // Z 轴单独试
```

分轴处理的妙处：斜着撞墙时，垂直分量被挡、平行分量放行——
角色**沿墙滑动**而不是被黏住。这个手感差异，试一次就懂。

### 任务三：工单 SD-401 —— 演技派上线（约 50 分钟）

回到 `Animator::update`，Idle 和 Walk 是引擎组的示范，Run 和 Jump 归你：

- **SD-401-a Run**：照着 Walk 抄结构，改三处——摆幅加大（腿 48°/臂 42°）、
  手臂端起来（armLift 向 12° 插值）、重心起伏（crouch 随 |cos(phase)| 波动）
- **SD-401-b Jump**：不用 sin 了，姿态由**垂直速度**决定——上升时剪刀腿
  （左前右后），下落时互换，双臂后摆+侧举保持"平衡"（其实是装的，但观众看着像）

写完验收：SHIFT 冲刺大开大合，跳跃全程有起跳-滞空-落地的姿态变化。
窗口标题栏实时显示当前状态（IDLE/WALK/RUN/JUMP）——这是穷人版调试 HUD，
盯着它检查状态机切换是否符合 1.1 节的转移图。
